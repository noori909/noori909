### Current Work

**Flexible MIMO Antenna System**  
*A Flexible MIMO Antenna System for Next-Gen Millimeter Wave IoT Enabled Smart Devices*

My current undergraduate FYP explores a flexible MIMO antenna system targeting the 24–30 GHz range.

| Focus | Current Direction |
| :--- | :--- |
| **Frequency** | 24–30 GHz |
| **Architecture** | MIMO |
| **Radiator** | Microstrip Patch |
| **Substrate** | Flexible |
| **Analysis** | ECC / Diversity |
| **Work Mode** | Electromagnetic Simulation |

The project sits at the intersection of antennas, electromagnetics, millimeter-wave systems, wireless communications, and computational engineering.

<details>
  <summary><b>Current investigation</b></summary>
  <br>
  The work is focused on understanding how antenna geometry, flexibility, MIMO behavior, impedance characteristics, isolation, and diversity performance interact across a continuous millimeter-wave operating band.
  <br><br>
  The project is currently simulation-oriented. Results and technical documentation will be added as the work progresses.
</details>
